### 2.2 [C002] ChatPage.jsx - Error Boundary 부재
**파일**: `src/pages/Chat/ChatPage.jsx`
**심각도**: CRITICAL
**유형**: 안정성

**문제**:
- ChatContainer 컴포넌트 크래시 시 전체 페이지 실패
- WebSocket 연결 상태 미표시
- 에러 복구 메커니즘 없음

**해결방안**:
```jsx
import { ErrorBoundary } from 'react-error-boundary';

function ChatPage() {
  return (
    <ErrorBoundary fallback={<ChatErrorFallback />}>
      <div className="h-full w-full">
        <ChatContainer />
      </div>
    </ErrorBoundary>
  );
}
```
